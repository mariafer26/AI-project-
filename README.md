## What does this project do?

Predicts whether a telecom customer will cancel their service (churn) using structured customer data (contract type, monthly charges, tenure, etc.). A rule-based AI agent then explains each prediction in plain language and suggests retention actions.

---

## Setup (run once)

```bash
# 1. Clone the repository
git clone <repo-url>
cd finalproject

# 2. Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate        # Mac/Linux

# 3. Install dependencies
pip install -r requirements.txt
```

---

## How to run

All scripts are inside the `src/` folder. Run them in order:

```bash
cd src
```

**Step 1 — Exploratory Data Analysis**
```bash
python eda.py
```
Downloads the dataset automatically and generates 4 plots in `reports/figures/`.

**Step 2 — Train models**
```bash
python train.py
```
Trains 3 models (Logistic Regression, Random Forest, Gradient Boosting) and saves the best one to `models/best_model.pkl`.

**Step 3 — Evaluate**
```bash
python evaluate.py
```
Prints accuracy, F1-score, ROC-AUC and a full classification report for all models.

**Step 4 — AI Agent**
```bash
python agent.py                      # random customer
python agent.py --customer-id 42     # specific customer by index
```
Shows churn probability, risk level, key risk factors, and personalized retention recommendations for a single customer.
